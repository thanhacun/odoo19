## Lessons (apply them)
- Admin-only tests hide most Odoo 19 problems. Always run screens as role users. Odoo 19 reads fields through `_search([('id','in',ids)])`: `_search` overrides must return `super()` for such lookups. Field `groups` on a field Odoo uses implicitly (`active`) breaks every search. Searching a Many2one with a model NAME reads `ir.model` (admins only). Custom fields on hr.employee are private unless also on `hr.employee.public`. Compute methods must assign every field and never `ensure_one()`. In lists `invisible="1"` hides only the cell (`column_invisible`). Our primary views must win by priority (lowest number wins; core is 16).
- Do not wait on "network idle" in Odoo (long polling). Never load unfiltered huge lists in Odoo 12 (470k attendance rows) from a script.
- Keep memory of what Thanh decided: see the Decisions paragraph above.
